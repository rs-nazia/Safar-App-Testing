# Safar - Android Jetpack Compose Application

Safar is an Android application built with Kotlin and Jetpack Compose.

## Project Structure

- `app/` - Main Android application module containing UI screens, Jetpack Compose components, and app logic.
- `backend/` - Backend service module / server code.
- `gradle/` & `build.gradle.kts` - Gradle build configuration.

## Getting Started

1. Open this repository in Android Studio.
2. Ensure you have the Android SDK configured.
3. Sync Gradle and build the app.
